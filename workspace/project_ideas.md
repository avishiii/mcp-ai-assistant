# Project Ideas

## 1. Smart Study Planner
Builds a weekly revision timetable from exam dates and syllabus size.
Priority: high. Estimated effort: 2 weekends.

## 2. Expense Tracker Bot
Telegram bot that logs expenses from chat messages and sends a monthly summary.
Priority: medium. Estimated effort: 1 weekend.

## 3. Campus Event Recommender
Recommends college events based on a student's interests using embeddings.
Priority: low. Estimated effort: 3 weekends.
